# 동그라미 마쓰야마 여행

2026.11.5(목) ~ 11.8(일) 마쓰야마 3박 4일 일정 공유용 모바일 PWA.

## 구조

```
index.html   앱 전체 (데이터 + CSS + JS 한 파일)
manifest.json
sw.js        서비스 워커 (오프라인 캐시)
icon-192.png / icon-512.png / icon-maskable-512.png
```

## 내용 수정하기

`index.html` 상단의 **`TRIP` 객체 하나**만 고치면 됩니다.

| 키 | 내용 |
|---|---|
| `title` / `periodLabel` / `start` / `end` | 헤더와 D-day |
| `weather` | 좌표 + 예보 범위 밖일 때 쓸 평년값 |
| `stay` | 숙소 카드 (전 일정 고정) |
| `days[].places[]` | 일정. 배열 순서가 그대로 번호가 됩니다 |
| `days[].meals` | 그 날 조식/중식/석식 |
| `foods[]` | 저녁 맛집 50곳 (날짜 무관 고정) |
| `phrases[]` | '식당 일본어' 버튼에 뜨는 문장 (묶음별 `ja` / `ko` 발음 / `mean` 뜻) |

- `q` 는 구글맵 검색어입니다. **일본어 이름**을 넣어야 정확히 잡힙니다.
- `detail` 안의 줄바꿈(`\n`)은 그대로 화면에 반영됩니다.
- `leg` 는 앞 목적지에서 여기까지의 이동입니다. 맨 앞에 이모지를 붙이면 그대로 나옵니다 (`✈️` 항공 / `🚐` 차량 / `🚶` 도보).
- `reserve` 는 `'필수' | '권장' | '불필요'` 셋 중 하나.
- `category` 는 `foodCategories` 에 있는 값만 씁니다. 칩은 4칸씩 두 줄 격자라서 '전체' 포함 8개가 딱 맞고, 늘리면 세 번째 줄이 생깁니다.
- `area` 는 `'도보권' | '전차 이동'`. 전차면 `transit` 에 가는 법을 적어주세요.
- 설명 끝의 마침표는 화면에서 자동으로 떼므로 찍든 안 찍든 됩니다.
- **수정 후에는 `sw.js` 의 `VERSION` 숫자를 올려주세요.** 안 올려도 두 번째 접속부터는 갱신되지만, 올리면 캐시가 즉시 교체됩니다.

## 맛집 추가 버튼

목록 맨 아래 `+ 맛집 추가` 로 식당 이름과 내용을 넣으면 바로 목록에 붙습니다.
저장 위치는 **그 기기의 브라우저(localStorage)** 라 다른 사람에게는 보이지 않습니다.

모두에게 보이게 하려면 `추가한 맛집 코드 보기` → `코드 복사` 로 나온 코드를
`index.html` 의 `TRIP.foods` 배열에 붙여 넣고 배포하면 됩니다.

## 아이콘

마쓰야마성 천수각 실루엣. 헤더 배경의 성 그림과 같은 모티프입니다.
바꾸려면 PNG 3종(192 / 512 / maskable 512)을 교체하고 `manifest.json` 을 맞춰주세요.

## 날씨

Open-Meteo 무료 API(키 불필요)를 호출해 날짜별 최고/최저·날씨·강수확률·바람을 표시합니다.

- 예보는 보통 2주 전부터 나옵니다. 범위 밖이면 `TRIP.weather` 의 평년값 카드로 자동 대체됩니다.
- 받아온 값은 `localStorage` 에 캐시되어, 현지에서 데이터가 끊겨도 마지막 값이 보입니다.

## GitHub Pages 배포

```bash
git add -A
git commit -m "여행 일정 PWA"
git push
```

GitHub 저장소 → **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** 저장.
1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.

모든 경로가 상대경로(`./`)라 저장소 이름이 무엇이든 그대로 동작합니다.

## 홈 화면에 추가

- **iPhone(Safari)**: 공유 → 홈 화면에 추가
- **Android(Chrome)**: 메뉴 → 앱 설치 / 홈 화면에 추가

설치하면 주소창 없이 전체화면으로 뜨고, 한 번 연 뒤에는 비행기 모드에서도 열립니다.

## 로컬에서 확인

서비스 워커는 `file://` 에서 동작하지 않으므로 간단한 서버를 띄웁니다.

```bash
python -m http.server 8000
# http://localhost:8000
```
